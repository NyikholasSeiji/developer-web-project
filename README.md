# 🛍️ Loja Virtual

Projeto desenvolvido em **Angular** com o objetivo de criar o frontend de uma loja virtual.

A aplicação será responsável pela interface do usuário, proporcionando uma experiência moderna, responsiva e intuitiva para navegação e compra de produtos.

Este README será atualizado conforme o desenvolvimento do projeto, incluindo informações sobre funcionalidades, tecnologias utilizadas e instruções de execução.

## 🚀 Tecnologias

* Angular
* TypeScript
* HTML
* CSS

## ▶️ Executando o projeto

Instale as dependências:

```bash
npm install
```

Inicie o servidor de desenvolvimento:

```bash
ng serve
```

Acesse:

```
http://localhost:4200
```
